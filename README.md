## Project Overview

This repository documents our phylogenetic analysis of selected frog species using mitochondrial cytochrome c oxidase subunit I (COI/COX1) gene sequences. DNA sequences were obtained from the NCBI Nucleotide database and analyzed in Galaxy through multiple sequence alignment, consensus sequence generation, and phylogenetic tree construction. This repository serves as our electronic laboratory notebook and archive for all outputs generated during the laboratory exercise.

---

## Biological Question

How are the selected frog species evolutionarily related based on their mitochondrial cytochrome c oxidase subunit I (COI/COX1) gene sequences?

---

## Objectives

- Retrieve COI sequences from NCBI.
- Perform multiple sequence alignment using Galaxy.
- Generate a consensus sequence.
- Construct a phylogenetic tree.
- Interpret the evolutionary relationships among selected frog species.
- Organize and archive all laboratory outputs using GitHub.
